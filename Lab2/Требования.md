# Лаба 2 — Deployment-диаграмма

Источник: Telegram «Materials 451001», топик «ООТПиСП» (сообщение от 28.09.2026 и ранее).

## Требования преподавателя
- Deployment-диаграмма в **том же проекте**, что и use-case (все диаграммы в одном проекте).
- Требования 1-й лабы сохраняются: масштаб 100 %, шрифт 14+ на **всех** надписях (включая подписи связей),
  диаграмма во весь экран без прокрутки (окно диаграммы вынести отдельно и развернуть), название = тема.
- Указывается оборудование для **всех актёров** из use-case.
- Сервер с БД и веб-сервер (приложения): указана архитектура, «прямоугольничек» с ОС, с фреймворком, с инсталляционным пакетом.
- Всё это в LAN, клиенты — через интернет.
- Браузеры: два самых популярных в Беларуси по statcounter
  (https://gs.statcounter.com/browser-market-share/all/belarus).
- Может заново проверить первую лабу.

## Как устроено у принятых работ
Внешние серверы (поставщик, платёжная система, SMS) и клиенты-пользователи — к «Интернет-канал» по HTTPS;
«Интернет-канал» — «Роутер» по HTTPS; менеджер и директор — к роутеру по HTTPS; «Сетевой принтер» — к роутеру по IPP;
«Сервер базы данных, архитектура Intel, разрядность x64» → ОС → СУБД → `*_list.sql`;
«Сервер веб-приложений, архитектура Intel, разрядность x64» → ОС → веб-сервер / сервер приложений / среда выполнения
и фреймворк + `*_store.deb`; связь веб-сервера с роутером: «HTTPS, <протокол СУБД>, IPP».

## Что сделано у нас (`Lab2/Touragency.qea`, пакет `deployment`)
- Рабочие станции гостя и авторизованного пользователя (через интернет), менеджера и директора (в LAN) — в каждой браузеры
  «Chrome for Android, Safari for iOS, Chrome 109.0 (Windows)».
- Сервер туроператора, сервер платёжной системы, сервер сервиса отправки SMS-кодов — через интернет.
- Сервер БД: Ubuntu Server 24.04.3 LTS (x64) → PostgreSQL 18 (x64) → `touragency_list.sql`.
- Веб-сервер: Ubuntu Server 24.04.3 LTS (x64) → Nginx 1.28 (обратный прокси), ASP.NET Core Kestrel 10.0,
  .NET 10.0 LTS + ASP.NET Core 10.0, `touragency_store.deb`.
- Генератор: `tools/ea_deploy/deploy.py` (раскладка и проверка; `save` — запись в модель).
